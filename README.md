# AeroTrip — Passenger Flight Assistant

A small HCI-focused passenger-side aviation web prototype.

## User
The primary user is a passenger who needs quick answers during an airport journey:
- Is my flight on time?
- Where is my gate?
- When does boarding start?
- What is my seat?
- What is my baggage allowance?
- What should I do next?

## HCI decisions
- **User-centered information hierarchy:** the "Next action" is placed prominently.
- **Recognition rather than recall:** gate, boarding time, seat and baggage information are visible without searching.
- **Visibility of system status:** flight state and journey progress are shown continuously.
- **Feedback:** passenger help actions open focused information panels and produce feedback.
- **Reduced cognitive load:** technical airline data is translated into passenger-friendly language.
- **Progressive disclosure:** extra details appear only when the passenger asks for them.
- **Accessibility basics:** semantic controls, readable labels, responsive layout and clear status text.

## Demo data
Flight numbers, airport times, seat, gate, baggage, walking time and status are fictional demonstration data. The prototype is not connected to live airline systems.

## Run
Open `index.html` in a modern browser. No backend or build step is required.

## Interview angle
This prototype demonstrates how HCI can simplify an aviation experience by starting from passenger questions and converting operational information into clear, actionable guidance.
